# REMOTE

Property management for Uganda, built with React, TypeScript, Express and PostgreSQL.

Frontend: https://remote-property-management.onrender.com

Backend: https://rent-app-foundations.onrender.com

The Phase 2 source adds shared workspaces, owner/manager/staff roles, monthly UGX invoices, payment allocations, landlord-specific mobile-money checkout, PDFs and an email delivery queue. Source changes must be deployed before these features appear on the live site. Mobile money and email require server-side provider configuration.

Active applications:

- Client: `week-4-fullstack-ts/day-21-ts-react/client`
- API and job command: `week-4-fullstack-ts/day-22-ts-node/server`

Earlier course folders remain as learning history. See [Phase 2 setup and rollout](PHASE2_SETUP.md), [organization permissions](week-4-fullstack-ts/day-22-ts-node/server/ORGANIZATIONS.md), and [landlord settlement setup](week-4-fullstack-ts/day-22-ts-node/server/PAYMENT_PROVIDER.md).
